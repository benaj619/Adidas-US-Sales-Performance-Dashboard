# Adidas US Sales Dashboard

## Project Overview

This Power BI dashboard provides an interactive analysis of Adidas US sales performance. It helps identify sales trends, regional performance, retailer contributions, and preferred sales methods to support business decision-making.

---

## Objectives

- Analyze overall sales performance
- Compare sales across different regions
- Evaluate retailer performance
- Monitor sales methods
- Track sales trends over time

---

## Tools Used

- Power BI
- Microsoft Excel
- Power Query
- DAX

---

## Dashboard Features

- Total Sales KPI
- Operating Margin
- Total Units Sold
- Sales by Region
- Sales by Sales Method
- Retailer Performance
- Monthly Sales Trend
- Interactive Retailer Filter

---

## Key Insights

- Total Sales reached **$899.90M**.
- The **West** region generated the highest sales.
- **Outlet** sales recorded the highest unit sales.
- Operating Margin stood at **41%**.
- Sales increased significantly during 2021.
